# XoaDynamicIsland

Too occupied while playing games to check the time? Why not have a pop-up that tells you it?

## How it is Made

This project is coded in C++ using CMake as its build system generator and Ninja as its build system

The project uses the following libraries:
* Raylib (SDL3 backend) by raysan5
* SDL3 by libsdl-org

## How to Run

1. Download the XoaDynamicIsland zip file from the latest release (XoaDynamicIsland_v1.0.zip in release v1.0)
2. Extract all contents
3. run Xoa.exe

## AI Disclosure

AI is only used to learn how the libraries used worked. No art or ideas were generated by AI.

## Final Mentions

* The app uses a 24-hour clock and a Month-Day-Year date format.
* Instead of having a close button in the app, the function has been replaced with hitting the ESC key right after clicking and focusing the app.
* The app is currently not draggable.
